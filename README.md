# Jolie Lopes Pavan - Portfólio Pessoal

Portfólio moderno em estilo Bento Grid inspirado no design de `bryan.szero.io`, desenvolvido com **Next.js (App Router)**, **Tailwind CSS**, **Framer Motion** e **Lucide React**.

## 🌐 Live
Acesse em: [https://joliepavan.github.io](https://joliepavan.github.io)

## 🛠️ Tecnologias
- **Framework:** Next.js 14+ (Static HTML Export)
- **Estilização:** Tailwind CSS (Dark Mode & Bento Grid)
- **Animações:** Framer Motion
- **Ícones:** Lucide React & SVGs customizados
- **Deploy:** GitHub Pages via GitHub Actions

## 💻 Rodando Localmente

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev
```

Acesse em [http://localhost:3000](http://localhost:3000).

## 🚀 Deploy
O deploy é automático via GitHub Actions ao fazer push na branch `main`.
